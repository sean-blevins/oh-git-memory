name: wrap-up
description: Close out a session - promote durable facts into memory, summarise the conversation, and write hand-off notes. Use when the user asks to wrap up, close out, finish, or hand off the project.
triggers:
- wrap up
- wrap-up
- close out
- hand off
---

When the user asks to wrap up (or to close out):

1. Promote durable entries from this conversation into the project memory file - or the global file if they apply everywhere. Ask before promoting anything ambiguous.
2. Summarise the conversation: what was asked, what was done, what is still loose.
3. Give hand-off notes: what to keep in mind for this project, and what to do when starting a new conversation.
